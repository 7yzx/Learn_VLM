# 简历项目总结（可直接使用）

## 项目名称
多模态 RLAgent for ChartQA（DAPO算法 + VeRL框架 + Think with Images）

## 项目背景
面向图表问答（ChartQA）场景，单次视觉-语言生成容易受到图中无关区域干扰，导致多步数值推理和多答案匹配准确率不稳定。项目目标是构建可执行工具调用的多模态 RLAgent：模型先生成工具动作（对图像局部聚焦/遮罩/高亮），再基于工具观测进行二次推理，并通过 DAPO/GRPO 风格强化学习持续优化策略。

## 核心工作
- 设计并实现 **两阶段 rollout** 训练闭环：首次生成 Action 代码 → 执行图像工具 → 构造二次多模态提示 → 二次生成最终答案，实现“Think with Images”。
- 基于 VeRL 改造训练主干，完成 **Ray + FSDP + vLLM** 分布式协同：vLLM 负责高吞吐采样，FSDP 负责策略/价值网络更新，支持多卡扩展与 checkpoint 恢复。
- 实现 ToolUse 执行链路（代码解析、白名单函数、安全上下文注入、失败惩罚），沉淀 `focus_on_*` 图像工具集（mask/draw/highlight，行列与坐标双维度）。
- 构建可插拔奖励系统（rule-based + LLM-judge），支持 `batch/llm_batch/llm_double` 多种 reward manager；在 ChartQA 上实现 `FINAL ANSWER` 解析、多答案匹配与数值相似度打分。
- 在策略优化层支持 `GRPO/GAE/RLOO/REMAX/REINFORCE++`，结合 DAPO 风格双侧 clip、KL 约束与在线样本过滤，提升训练稳定性。
- 建立训练可观测体系：记录 reward/kl/advantage/throughput，同时新增 `tool_call_ratio`、`tool_call_success_rate` 与 trace 图像日志，支持行为级调参与错误定位。

## 可选精简版（1-2行）

基于 VeRL 构建多模态 ChartQA 强化学习 Agent，打通“工具调用-图像反馈-二次推理”两阶段 rollout 闭环；在 DAPO/GRPO 训练框架下实现可插拔奖励、分布式高吞吐训练与行为级可观测，提升复杂图表推理稳定性与可解释性。
